# EMZ Contnet

EMZ Content Studio: a calendar for the client and content/design teams.

## Use

Open the live GitHub Pages site, select a post to see its idea, reference, caption, publication date and time, and final file URL. Use Team workspace to edit the plan.

Edits are saved in the current browser on the current device. They do not automatically sync across team members or update this repository. Use Save & share to export the updated HTML or a JSON backup. To update the hosted plan, replace index.html with the exported HTML and commit the change.

This app does not publish posts to social platforms.
